## v1.11 专属场景图

v1.11使用 `scenes/batch-000.webp` 至 `scenes/batch-118.webp`：119份2×2图版，各格都是按具体轮次、地点、行动或执行结果单独生成的完整3:2照片。473个新增场景各有独立图格；卷首与14种结局继续使用已经独占的15张图，合计488个绑定，无跨场景重复分配。全部资源与审核记录已经通过验收，待生成和待修正清单均为空。

`scene-art-manifest.js` 绑定稳定场景ID与图格。刷新、恢复存档和档案回看同一段历史时，显示该场景自己的照片。图片按当前页面加载，图版内的四格可共享一次下载；这不表示不同场景共用同一张照片。

所有新图保持炭黑阴影、暖纸色高光、低饱和自然色和少量暗红。镜头按故事安排室内、街头、生产、交通、战地与日常生活；人物使用明确的外貌锚点。安娜的界面肖像已与新场景中的同一人物对齐，其余十一位历史人物肖像保留原有形象。

逐场景文字依据、生成提示、图版审核记录位于 `docs/scene-art/`。`npm run audit:scene-art` 检查唯一分配、资源存在、原生尺寸和审核记录。下列旧图版说明保留为旧版本素材记录，v1.11新周目通过独立绑定显示配图。

全部为本次由 ImageGen 生成的历史场景演绎。统一暖灰黑白胶片质感、低饱和、单侧光、深色阴影，无现代物件或文字。WebP 质量86，页面不作改变人物体型的拉伸；先按原生3:2裁出单元，再做响应式居中裁切。
