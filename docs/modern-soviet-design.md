# v1.9 现代苏联主题与年报综合图

两个网址使用同一份静态前端。此次统一首页、剧情会谈、决议、统计、新年手记和结局档案的视觉层级，保留既有图片、人物、剧情和数值规则。

## 设计依据

以苏联主题的红、黑与暖纸色建立品牌，参考 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) 的内容层级和导航原则，以及 [Microsoft Fluent 2 的间距系统](https://fluent2.microsoft.design/layout)与[字体层级](https://fluent2.microsoft.design/typography)。采用统一间距、有限字重、可见选中状态和适配不同屏幕的组件。

| 用途 | 颜色 |
| --- | --- |
| 主要操作与强调 | 苏联红 `#ad2635` |
| 导航、封面和结果背景 | 炭黑 `#18191b` |
| 页面底色 | 暖纸 `#efebe2` |
| 对白、数据与档案卡片 | 象牙白 `#fffdf7` |
| 少量年代装饰 | 暗金 `#a57c39` |

首页使用黑色分栏封面、独立标题、红色主操作和五幕图版卡片。剧情保持连续阅读，消息、对白、回应与执行后果分层呈现。国家概览改为轻量数据卡；统计选中项使用暗红。图鉴在大屏为三列、手机为两列，已解锁封面与记录入口保持可读。桌面侧栏与手机底部导航使用同一组本地SVG图标，阅读与结局详情均有准确的当前页面标记。

资源引用带版本号，避免更新后混用旧样式与新脚本。原有CSS保留基础排版，`experience.css`承担当前设计系统，`endings.css`承担档案布局。

## 年报综合折线图

每份新年报告及历史年度手记展示同一年的九项指标：政治资本、偏执、工业、红军、民心、阵营影响、斯大林派、左翼、右翼。

- 年初基线来自该报告的`start`，中间点来自该年份真实事件，终点与报告的`end`核对。
- 纵轴为原始游戏数值，共用坐标。可点图例单独显隐指标；纵轴随显示的数据调整，没有百分比化或虚构增减。
- 颜色与线型共同区分指标，图例按钮使用`aria-pressed`。键盘和触摸均可通过滑块检查每个事件的九项数值及当次变动。
- 所有曲线隐藏时保持稳定的空坐标，不报错或显示无效数值。重新点图例即可恢复。
- 没有新结算的年份显示沿用报告的水平线，并明确说明数据来源，不把未观测年份伪装成发生了新事件。
- 综合图由既有统计动态生成，不改写存档，不重复结算；历史通关档案也会自动获得这一视图。

## 验证与证据

188项单元测试通过。新增检查逐年核对综合图年初、年末与九条序列，覆盖没有新事件的年份和数据不可变性。真实浏览器验证图例显隐、全部隐藏、滑块、九项准确值、游戏状态不变及320／390／768／1440px布局。

对话、常设决议、存档恢复、完整周目、战报、统计与档案备份浏览器检查继续通过。另在320、390、768、1024、1440px检查首页、会谈、政策结果、常设汇报、统计、图鉴和结局详情，共35种页面状态，无横向溢出或图片加载失败。

改版前后截图及布局报告在`docs/qa/modern-soviet/`。综合图截图在`docs/qa/statistics/annual-combined-1440.png`与`annual-combined-390.png`。实际打开复查后修正了暗红档案区标题对比度，并将统计测试限定在对应组件中，避免隐藏年报图影响选择器。
