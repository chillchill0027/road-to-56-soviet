# v1.2 全路线与事件结算验收

2026-10-16 · 当前结果：通过。

14 种结局均有从新游戏开始、只使用可见选项与可支付决议完成的正常路线。24 条固定回放同时覆盖全部 56 个场景、124 个选项、23 项决议，以及所有 4 种交接方式、5 种战争结果、5 档战役结果和 6 类幕间清洗事件。另有9项独立入口检查，分别验证军方接管/朱可夫、左翼影响力/政变、右翼影响力/改革与党内讨论的两种前置。每条回放验证数值边界、时间顺序、存档恢复、图鉴记录和资源真实扣除。

固定路线保存在 `tests/fixtures/routes.json`。完整浏览器检查只点击页面中的按钮、使用玩家快捷键，并控制随机种子；不会向玩家状态注入资源、路线或解锁记录。同一个浏览器档案通过正常游玩收集到了 14/14 结局，截图为 `docs/qa/all-endings-gallery.png`。

## 路线修复

| 路线 | 准备与后果 |
|---|---|
| 永久的革命 | 序幕选择容忍或分化后，第一、二幕的“恢复党内讨论”每次消耗政治资本30；两派各+10、民心+3、斯大林派−5、偏执+5。最多2次，可正常解锁共产国际、左翼政变与继承路线。 |
| 技术官僚的秩序 | 第一幕任用贝利亚获得势力15；“内务部专项授权”每次消耗政治资本30，势力+15、偏执−5、民心−4、斯大林派−3，最多2次。第四幕定向清算可继续增加势力，但仍损害民心和科研。 |
| 平庸的延续 | 继承争论增加H“临时委员会留任”：民心−5、阵营影响−5。明确选择延续惯性，不再依赖无法触发的无路线兜底。数字8与字母H均可选。 |

“被军队/内务部接管”表示1953年权力真空中的临时控制；继承争论决定长期制度。清退元帅会真正清除其自动接管资格，部分清洗不会再把仍在世的图哈切夫斯基写成已死。莫斯科的全权委任和库尔斯克的防御方案各在获胜时增加朱可夫威望20；两次胜利可独立达到40，无需图哈切夫斯基发动政变。临时军方接管也可在继承阶段正式确认。

## 数值与事件因果

- **统一真实账本**：自动事件、选择、决议和战役都按结算前后差额显示净变化。核进度、人物势力、外交信任、工事、工业东迁等同样计入；封顶只显示实际增加量，不重复列出同一指标。
- **投资有支付门槛**：原子弹、机械化、炮兵、筑防、运输、核援助等工业投资必须有足够产能；缺少资源时保留可执行的替代选择。满战力不再继续收取无效扩产费用，核进度满额后停止收取氢弹投资。
- **决议成本一致**：宪法使清洗决议的政治资本成本降低20%；共产国际路线使战时租借决议的政治成本翻倍。成本显示、可执行状态与实际扣款共用同一规则。消费品生产明确消耗工业20、民心+12。
- **战场修正生效**：敌军修正适用于后续各场战役，且每场只计一次。有效敌军强度下限20；工事有效上限48。屏障部队的25%加成只作用于标记为防守/死守的战术。
- **失败不会领奖**：战术成本在各档结果中均会结算；胜利专属加分只在“守住/反攻”时发放。柏林占领标记需要真正取胜；失利时不再播放胜利文案。
- **长期后果落地**：工业东迁在战争结算时恢复实际产能，最多15；北线未缓冲会在列宁格勒造成一次性工业与民心损失；全面去斯大林化引发的阵营动荡会产生实际影响，联合政府安排可减轻冲击。外交信任可为负，后续让步需要先弥补信任赤字。
- **时间与叙事一致**：选择延后战争后，战时年份随之顺延；新周目先结算战争再举行战后会议，柏林危机先于核试验，内部清算在1952年。结局报告依照实际去斯大林化选择与元帅存活情况生成。
- **颜色表达正确**：偏执、民族问题、阵营动荡上升标为负面；敌军强度下降标为正面；派系和人物势力保持中性。

## 全部结局的判定（含剧透）

下表按优先级排列。较高优先级的国家整体结果会覆盖继承人路线；游戏中选定某位继承人不等于忽略此前的战争与外交后果。

| 结局 | 主要条件 |
|---|---|
| 苏维埃的黄昏 | 战役崩溃至少3次，或未战败但最终民心不高于15。 |
| 第三罗马 | 战败、至少2次宗教和解、最终民心不高于35，且未触发更高优先级的黄昏。 |
| 孤岛 | 阵营影响不高于20、民族问题至少50。 |
| 缓和 | 选择核裁军，最终西方信任至少20。 |
| 共同经济体 | 成立经互会，最终工业至少190。 |
| 钢铁的永恒 | 1953年被暗杀，或延续斯大林路线且最终偏执至少80。 |
| 伟大的继承人 | 选择集体领导。报告内容依全面/有限/未批判分别呈现。 |
| 技术官僚的秩序 | 贝利亚势力至少40后选择技术官僚改革。 |
| 红色拿破仑 | 朱可夫威望至少40或军方已进入政坛后，选择军队执政。 |
| 新经济道路 | 右翼至少60或已实施新经济政策后，选择新市场社会主义。 |
| 永久的革命 | 左翼至少60或已发生左翼政变后，选择第四国际路线。 |
| 全权苏维埃 | 序幕选择容忍、继承阶段民心至少70，选择还政于苏维埃。 |
| 无声的独裁 | 选择延续斯大林路线，且未被前述整体结果覆盖。 |
| 平庸的延续 | 选择临时委员会留任，且未被前述整体结果覆盖。 |

## 兼容与验收

已有v1存档继续读取，已解锁的图鉴保留。旧存档保留原场景顺序，避免改动排序后跳过会议或重复决议；新周目使用修正顺序。旧结果页恢复显示已结算结果，不重新扣款、领奖或随机清洗。

```sh
npm test                    # 游戏、事件和全路线回放
npm run test:browser        # 标题、指南、键盘及续玩交互
npm run test:browser:routes # 桌面/手机真实点击24条完整路线
```

- `docs/qa/route-coverage.json`：250项分支覆盖与14个结局的验证结果。
- `docs/qa/browser-routes.json`：真实浏览器回放、资源错误、页面异常、图鉴14/14。
- `docs/qa/browser-smoke.json`：核心操作与续玩检查。
- `scripts/find-routes.cjs`：通过合法操作搜索路线；固定验收不会在运行时重新生成路线，以免掩盖回归。

GitHub CI执行同样的回归；发布后的检查先比对线上脚本与样式是否和提交一致，再在公开网址重放全部路线。验证覆盖当前提供的场景、选项与条件分支；后续新增内容必须补齐固定回放后才能通过覆盖检查。
