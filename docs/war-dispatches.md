# 战地卷、战果图文与地点 · v1.6

每场战斗结算后，会收到战区照片、前线电报、后勤报告、普通人的来信和位置示意。图文依据实际战果，使用已经完成的结算；阅读、刷新与打开档案不会重新计算战斗。

## 战区与照片

七个战区分别覆盖西部边境、莫斯科、斯大林格勒—伏尔加河、库尔斯克、白俄罗斯、雅西—基什尼奥夫和柏林。1944年选择南线时，月份、地貌、照片、地名和位置示意一并切换到普鲁特河谷，不再沿用白俄罗斯素材。战争延后到1942年开始时，报告年份随实际游戏年份移动。

新增八组WebP图集，共32张写实战地场景：七组战区照片与一组战后照片。每个战区包含撤收重组、相持、防御支点、局部反攻四类画面；崩溃与失守均使用撤收类照片，文字分别表现建制中断与有组织后撤。战争总结果使用停战撤收、惨胜后的重建、胜利后的生活或未解除警戒的停战线。

镜头按事件分别设计，包含指挥所、电台、撤离车站、面包房、船舱、浮筒系缆特写、空中观察、铁路维修与室内近战。运动场面检查车辆、人员与扬尘方向是否相符。图像保持统一的低饱和胶片风格、相应年代的制服与装备。镜头以中远景、背影和普通士兵为主，没有引入新的领袖面孔；既有人物仍复用原来的肖像。所有照片为AI历史演绎，不是真实史料。

## 战报范围

- 35组战斗版本：七个战区各自对应崩溃、失守、僵持、守住、反攻。
- 五组战争总体结果：战败、惨胜、伟大胜利、守住本土、僵持和平。局部反攻不自动代表战争总体胜利。
- 13组政策行动报告：冬季战争与北线安排、列宁格勒围城、华沙起义和让盟军先进入柏林。此类行动保留原本的政策结算，不虚构新的战力比或战斗评级。

共53组结果图文，含146条前线、后勤、民众或后续事务短讯。原本可能在失守后仍出现的固定胜利描述，改为本次真实结果的文案。守住柏林桥头堡不会直接写成整座城市已经攻克；南线一次推进不会直接宣布整个巴尔干易手。

位置示意使用相关城市与河流区域的约略经纬度，显示本次战区及关联地点。连线为阅读示意，不作为实际道路、实时战线或领土控制图。不会因为地图画到一个城市，就额外确认城市已经易手。

## 存档与回看

每项已结算行动只保存一份战报。报告记录年份、所选命令、实际结果、图片、地理信息、短讯和实际数值变化，在“见闻档案 → 战地卷”中回看。通关后的最后一份战地卷保留在当前浏览器，刷新后仍可查阅；新周目的记录独立累积。原有战力公式、成本、奖励和年度统计继续工作。总体结果中的守住与反攻次数分别展示，避免将反攻重复计入总场数。

旧存档可继续运行。缺少新战地档案的旧结果页按其已保存的战果展示，不重复结算，也不伪造之前的完整战斗记录。

## 验证

`npm test`包含179项检查：24条合法路线有无战报功能的完整状态对比、35组战斗版本、五种战争总结果、七个战区、南线地理切换、延后开战年份、旧结果兼容和地图无障碍ID。

`npm run test:browser:war`以真实按钮完成南线路线，检查八组图片、实际战果与图片对应、战报读档、档案不可重复执行政策、320/390/768/1440px排版以及最终战争汇总。全路线浏览器验收同时逐战斗核对显示的结果、地图战区和三类短讯。公开页面执行相同专项与全路线检查。

专项截图和报告保存于`docs/qa/war/`，公开网页验收记录由GitHub Actions保存。
