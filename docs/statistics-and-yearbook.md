# 国家统计与新年手记 · v1.5

顶部“国家统计”提供政治资本、偏执、工业、红军、民心、阵营影响与三个派系的九项指标。点击指标可切换折线；下方时间线支持鼠标、触控和方向键，逐条显示事件名称、在任领导人、实际数值与本次增减。完整表格提供相同数据，便于查阅。

## 统计口径

- 新周目从1936年的初始状态开始。政策、常设决议和产生实际变化的阶段结算各记录一次，包含战役与数值上限产生的实际结果。
- 多轮对话尚未形成政策时不记录资源变化。刷新、读档、翻阅资料、查看统计和年度手记都不结算效果，不消耗随机数。
- 横轴为事件结算顺序，标注对应年份。同年可以出现多个点；纵轴为当前所选指标的实际值，从零开始。没有新事件的年份不插入虚构增长。
- 偏执越低越好；派系强弱不标记为好坏。各指标分别绘制，避免混用量程。
- 旧存档从接续时的状态开始记录，无法重建的早年数据不补造。原有路线和存档流程保留。

## 每年的总结

进入新年份前，先封存上一年的年末状态，再应用新阶段的效果。新年手记包括年末数值、较年初的变化、实际签署的政策与决议，以及第一人称的国家回顾。战争结果、核工程推进与新增清洗会依据本周目的实际结果加入回顾。年度回顾不额外改变国家数值。

1936—1956共21份年末记录。1956年最后结算后，也会展示最后一年的回顾。剧情跨过的空白年份逐年保留手记，明确说明沿用最近一份报告，不把缺少记录解释为真实国家没有变化。

叙述者使用年末的最高领导席位。1952年的手记仍由斯大林叙述，1953年继承决定落实后，年末记录改为实际继承人。人物沿用现有肖像；赫鲁晓夫、贝利亚与军方领导席位有相应语气。其他继承路线保持其实际名字和席位。手记为原创历史演绎。

跨年弹窗可逐年翻页，也可用Escape收起当前一份。未阅读的手记和待展示队列写入存档，刷新后继续，不重复记账。在“国家统计 → 新年手记”可随时回看。通关后最后一份完整统计档案保留在当前浏览器；下一周目的统计独立累积。
