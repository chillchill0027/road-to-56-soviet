# v1.4：案头与耳畔

主画面减少规则与背景讲解，改由角色在故事中接触到的消息交代局势。30类来源共147条材料分布于37段决策、10段过场与23项常设议题；不是仅在设置里列出名称。

开场先看1934年的旧报剪页，再听1936年当日广播，最后经过办公室门外的交谈进入会见。第一项政策不再是开场第一屏。旧闻明确注明日期，当前年份与领导席位沿用游戏实际状态。

来源具有不同的口吻与呈现形式：新闻、声音、电文、书信、账簿与文件。短材料在新的信息到达时出现，普通往复交谈不重复显示同一张卡。影像会在消息出处与谈话地点间切换。

战争汇总、科研记录、军官状态和权力交接消息使用当时的真实游戏状态。战败不会收到胜利报告；军方或内务部临时接管不会被写成同一份自然死亡讣告。读过的材料保存当时的文本，之后数值改变不会重写旧消息。

## 画面与存档

新增12张AI生成场景：报亭、克里姆林宫走廊、厨房家书、撤运车站、通讯社、监听室、密电案头、战地电话、工厂食堂、实验台、面包店队伍、交接期等候室。存储于三张WebP图集，沿用档案摄影风格。人物继续复用既有12人肖像，避免同一人物在不同场景换脸。

主画面移除了反复出现的累计规则、资源提醒、轮数依据、前情说明和上一句复述。规则留在游玩指南，收到的消息与原有对白一起进入“见闻档案”。旧版直接国策存档继续读取；v1.3对话存档可以在当前轮次继续，无需清空进度。过场阅读页码和消息快照也会保存。

报刊、档案与对白均为剧情重构，不宣称是历史原文。背景图片也不是原始档案照片。说明集中在指南与本文，避免反复打断故事。

## 验证

`npm test`检查来源覆盖、出现时点、实际状态、消息快照与存档恢复；`npm run test:browser:immersion`检查开场、消息先于回应、说明文字移除、档案回看、图片加载与窄屏。`npm run test:browser:routes`在24条真实路线中采集实际看到的来源类型，少于20类会失败，并继续验证原有250项目标与14个结局。

截图与报告保存在`docs/qa/immersion/`，全路线来源记录保存在`docs/qa/browser-routes.json`。公开网页发布后执行同样的检查。
