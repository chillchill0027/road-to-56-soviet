# 56之路：苏维埃

从 1936 年到 1956 年，扮演国家意志，在工业、战争、派系与民心之间做出抉择。五幕叙事与序幕、56 个流程节点、124 个选项、23 项决议和14 种主结局；战役由数值计算，结局还叠加战争与冷战结果。

## 在线游玩

直接打开 [游戏网页](https://chillchill0027.github.io/road-to-56-soviet/)。GitHub Pages 从 `main` 发布；部署后会自动运行公开网页与资源检查。

## 本地运行

安装 Node.js 20 或更新版本后：

```sh
npm run dev
```

浏览器打开 `http://localhost:4173`。运行游戏不需要安装依赖或构建，也可以用任意静态服务器托管项目根目录。支持 GitHub Pages 的项目子目录路径。

## 游玩与存档

- 点击选项，或按显示的 A–H / 1–8 快捷键；Enter / 空格继续。
- 顶部“游玩指南”说明属性和战役公式；Escape 关闭弹窗。
- 进度自动保存在当前浏览器，包括选择后的结果页。返回标题或刷新后可继续。
- 开始新游戏前会提示替换已有进度；结局图鉴不会随新游戏清空。
- 原版 v1 存档仍可读取，流程位置按场景 ID 迁移。

存档不跨设备同步。无痕模式、浏览器存储被禁用、清理网站数据会影响进度保留。

## 验证

```sh
npm test
npm ci
npx playwright install chromium
npm run test:browser
npm run test:browser:routes
```

浏览器验证可自动启一个静态服务器。核心交互检查保存在 `docs/qa/browser-smoke.json`；全路线检查以真实按钮操作24条完整路线，在同一浏览器档案收集14/14结局，覆盖所有场景、选项与决议，并检查实际扣款、数值显示、读档和横向溢出。全路线报告保存到 `docs/qa/browser-routes.json`。也可以设置 `CHROMIUM_PATH` 使用已有 Chromium。

v1.2 的具体修复、数值规则和全结局条件见 [路线与数值验收](docs/routes-and-balance.md)。旧存档保留原场景顺序，已解锁图鉴不清空；新周目使用修正后的顺序。

设计对照与验收记录见 [design-qa.md](design-qa.md)。原始剧情设计见 [设计与流程](56之路-苏维埃RPG-设计与流程.md)。

## 视觉与素材

档案纸、深橄榄黑与暗红组成视觉系统。桌面采用左图右文，手机采用纵向阅读。25 张独立场景照片以六张四宫格与一张封面存储为 WebP，页面按单元裁切；三张领袖场景在同一次生成中使用相同人物、服装、军帽及背影/侧影设定。所有照片均为 AI 生成的历史场景演绎，不是真实档案照片。

`assets/fonts/archival-serif.woff2` 是 Noto Serif CJK SC SemiBold 的项目字符子集，字体许可见 `assets/fonts/OFL.txt`。其余界面文字使用系统中文字体。素材均在本地托管，不依赖图片 CDN 或在线字体服务。

## 文件

- `script.js`：场景、数值、战役、存档、结局和基础渲染。
- `presentation.js`：导航、指南、新游戏确认、阅读布局与无障碍焦点。
- `style.css`：响应式视觉样式及减少动态效果支持。
- `assets/images/`：封面与场景图集。
- `tests/`：游戏回归测试及浏览器完整周目验证。
