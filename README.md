# 56之路：苏维埃

从1936年到1956年，先扮演斯大林，再转入继承人的最高领导席位，国家意志贯穿全程。37段重大事件展开为185轮情景互动，23项常设议题也通过交谈形成决定；五幕与序幕、56个流程节点、124项政策与战果结果和14种结局保留。战役与国家整体后果继续影响最终历史。

## 在线游玩

直接打开 [游戏网页](https://chillchill0027.github.io/road-to-56-soviet/)。GitHub Pages 从 `main` 发布；部署后会自动运行公开网页与资源检查。

也可以打开 [GPT 网页作品](https://road-to-56-soviet.chillchill0027.chatgpt.site/)。两个网址的浏览器存档独立，可通过游玩档案备份转移通关记录。

## 本地运行

安装 Node.js 20 或更新版本后：

```sh
npm run dev
```

浏览器打开 `http://localhost:4173`。运行游戏不需要安装依赖或构建，也可以用任意静态服务器托管项目根目录。支持 GitHub Pages 的项目子目录路径。

## 游玩与存档

v1.9统一现代苏联主题：苏联红、炭黑、暖纸色，大幅封面、图标导航、清晰对白与数据卡片。每份新年报告增加九项指标的综合折线图，支持图例显隐与逐次事件查阅；历史年度手记和通关档案同步可用。详见[设计与综合年报](docs/modern-soviet-design.md)。

v1.8为14种结局加入专属写实封面。图鉴可打开每次通关的九项指标曲线、事件数值、政策记录与年度手记，同一结局的多次游玩分别保留。支持导出与导入备份；旧版未留存的数据明确标注。详见[结局与游玩档案](docs/ending-archive.md)。

v1.7参考 Apple Music 的大幅封面、留白与导航层级，保留黑、纸黄、暗红配色。桌面侧栏、手机底部导航与章节封面便于浏览，正文保持连续阅读。23项常设决议各有独立会见，一次回应即可批准或暂缓；重大历史事件仍为3／5／7轮。每段事件补充开场、前一次回应和会谈后叙述。详见[沉浸阅读与一次批示](docs/immersive-experience.md)。

v1.6.1统一黑、纸黄与暗红的档案式界面，优化首页、对话选项、国家统计、弹窗和手机导航。原有人物图像、剧情、数值与存档规则继续沿用。

v1.6新增战地卷：32张写实场景图、七个战区的差异化战报、实际战果对应的地点示意与档案回看。详见[战地卷与地理](docs/war-dispatches.md)。

v1.5新增“国家统计”：九项指标折线图、逐次事件数值表，以及1936—1956年的新年手记。新年回望上一年，使用年末在任领导人的第一人称；继承后切换人物。详见[统计与年度总结](docs/statistics-and-yearbook.md)。

v1.4通过30类新闻、密电、来信、报告和身边谈话交代实时背景，补充147条情境材料与12张场景图。开场先读消息再进入会见；玩法说明集中在指南，收到的材料可在“见闻档案”回看。见[案头与耳畔](docs/in-world-sources.md)。

- 点击选项，或按显示的 A–H / 1–8 快捷键；Enter / 空格继续。
- 每段重大决定包含3／5／7轮回应，按决策酝酿时间安排；累计表态自动形成政策。次数并列时采用其中最近一次表态，结果页可查看依据。
- 常设决议只需一次回应，批准时一次结算，暂缓不拨款。旧存档中未结束的常设会谈保留已说过的话，再作一次最终批示。
- 顶部“见闻档案”回看人物原话与自己的承诺，继承后按新领导席位继续。
- 顶部“游玩指南”说明属性和战役公式；Escape 关闭弹窗。
- 进度自动保存在当前浏览器，包括选择后的结果页。返回标题或刷新后可继续。
- 开始新游戏前会提示替换已有进度；结局图鉴和逐次通关档案不会随新游戏清空。
- 原版 v1 存档仍可读取，流程位置按场景 ID 迁移。

存档不跨设备同步。无痕模式、浏览器存储被禁用、清理网站数据会影响进度保留。

## 视觉与素材

纸黄、黑与暗红组成视觉系统。首页采用大幅封面与章节封面索引，剧情采用纵向阅读。83张场景照片、12个人物肖像存储于23个WebP文件中。人物在不同场景复用同一档案肖像；三张领袖背景使用相同人物、服装、军帽与背影/侧影设定。所有照片均为AI生成的历史形象与场景演绎，不是真实档案照片；文学化对白不是真实引语。

`assets/fonts/archival-serif.woff2` 是 Noto Serif CJK SC SemiBold 的项目字符子集，字体许可见 `assets/fonts/OFL.txt`。其余界面文字使用系统中文字体。素材均在本地托管，不依赖图片 CDN 或在线字体服务。

## 文件

- `script.js`：场景、数值、战役、存档、结局和基础渲染。
- `presentation.js`：导航、指南、新游戏确认、阅读布局与无障碍焦点。
- `novel-content.js`：37段情景对话、23项议题与人物资料。
- `world-content.js`、`world.js`：30类情境消息、过场阅读、消息快照与见闻档案。
- `novel.js`：多轮互动、自动归纳、领导视角、对话记忆与回看。
- `war-content.js`、`war.js`：分战区和实际战果的图文报告、地点示意与战地卷。
- `statistics.js`：结算快照、折线图、事件查阅与领导人年度手记。
- `endings.js`、`endings.css`：逐次通关档案、结局封面、历史曲线与备份。
- `style.css`：响应式视觉样式及减少动态效果支持。
- `experience.css`：封面、导航、阅读与一次批示的视觉层。
- `assets/images/`：封面与场景图集。
- `tests/`：游戏回归测试及浏览器完整周目验证。

非官方同人作品，灵感来自《钢铁雄心 4》Road to 56。
