# 56之路：苏维埃

从1936年到1956年，先扮演斯大林，再转入继承人的最高领导席位，国家意志贯穿全程。37段重大事件展开为185轮情景互动，23项常设议题也通过交谈形成决定；五幕与序幕、56个流程节点、124项政策与战果结果和14种结局保留。战役与国家整体后果继续影响最终历史。

## 在线游玩

直接打开 [游戏网页](https://chillchill0027.github.io/road-to-56-soviet/)。GitHub Pages 从 `main` 发布；部署后会自动运行公开网页与资源检查。

## 本地运行

安装 Node.js 20 或更新版本后：

```sh
npm run dev
```

浏览器打开 `http://localhost:4173`。运行游戏不需要安装依赖或构建，也可以用任意静态服务器托管项目根目录。支持 GitHub Pages 的项目子目录路径。

## 游玩与存档

v1.4通过30类新闻、密电、来信、报告和身边谈话交代实时背景，补充147条情境材料与12张场景图。开场先读消息再进入会见；玩法说明集中在指南，收到的材料可在“见闻档案”回看。见[案头与耳畔](docs/in-world-sources.md)。

- 点击选项，或按显示的 A–H / 1–8 快捷键；Enter / 空格继续。
- 每段重大决定包含3／5／7轮回应，按决策酝酿时间安排；累计表态自动形成政策。次数并列时采用其中最近一次表态，结果页可查看依据。
- 顶部“对话记录”回看人物原话与自己的承诺，继承后按新领导席位继续。
- 顶部“游玩指南”说明属性和战役公式；Escape 关闭弹窗。
- 进度自动保存在当前浏览器，包括选择后的结果页。返回标题或刷新后可继续。
- 开始新游戏前会提示替换已有进度；结局图鉴不会随新游戏清空。
- 原版 v1 存档仍可读取，流程位置按场景 ID 迁移。

存档不跨设备同步。无痕模式、浏览器存储被禁用、清理网站数据会影响进度保留。

## 视觉与素材

档案纸、深橄榄黑与暗红组成视觉系统。桌面采用左图右文，手机采用纵向阅读。37张场景照片、12个人物肖像存储于11个WebP文件中。人物在不同场景复用同一档案肖像；三张领袖背景使用相同人物、服装、军帽与背影/侧影设定。所有照片均为AI生成的历史形象与场景演绎，不是真实档案照片；文学化对白不是真实引语。

`assets/fonts/archival-serif.woff2` 是 Noto Serif CJK SC SemiBold 的项目字符子集，字体许可见 `assets/fonts/OFL.txt`。其余界面文字使用系统中文字体。素材均在本地托管，不依赖图片 CDN 或在线字体服务。

## 文件

- `script.js`：场景、数值、战役、存档、结局和基础渲染。
- `presentation.js`：导航、指南、新游戏确认、阅读布局与无障碍焦点。
- `novel-content.js`：37段情景对话、23项议题与人物资料。
- `world-content.js`、`world.js`：30类情境消息、过场阅读、消息快照与见闻档案。
- `novel.js`：多轮互动、自动归纳、领导视角、对话记忆与回看。
- `style.css`：响应式视觉样式及减少动态效果支持。
- `assets/images/`：封面与场景图集。
- `tests/`：游戏回归测试及浏览器完整周目验证。

非官方同人作品，灵感来自《钢铁雄心 4》Road to 56。
